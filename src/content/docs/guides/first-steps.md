# Primeros Pasos

Esta guía te ayudará a familiarizarte con la estructura del proyecto.

## Estructura de carpetas
```
src/
├── content/docs/    # Archivos Markdown
├── components/      # Componentes reutilizables
├── layouts/         # Layouts de página
└── pages/           # Rutas de la aplicación
```

## Crear nueva documentación

Para crear una nueva página de documentación:

1. Crea un archivo `.md` en `src/content/docs/`
2. Agrega el frontmatter con título y descripción
3. ¡Comienza a escribir!
